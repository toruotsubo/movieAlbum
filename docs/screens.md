# Screens

## キー項目一覧画面・動画一覧画面共通ナビゲーション

### Elements

- キー項目一覧と動画一覧の遷移ボタン
- 「設定」ボタン
- フィルターメニュー、ソートメニュー

### Behavior

- 「設定」ボタンをクリックすると、設定モーダルを表示

## キー項目一覧画面

### Purpose

キー項目の一覧を表示する。

### Elements

- サマリー画像
- キー項目値
- 動画数
- タグ、評価
- 「編集」ボタン
- 「動画一覧」ボタン

### Behavior

- 画面の名称は「#{キー項目名}一覧」
- 各動画のタグ、評価とは別に、キー項目のタグ、評価がある
- タグ、評価によるフィルター
- キー項目によるソート
- サマリー画像はキー項目に紐づいた動画のうち評価が高いもの1点を自動的に選択する。選択はキー項目一覧画面表示時に行われる。
- 日本語モードでキー項目値が「名前」の場合は「名前（ふりがな）」でソート
- 評価はマウスクリックにより変更できる。変更時即座に反映
- 「編集」ボタンをクリックすると、キー項目編集モーダルを表示
- サマリー画像または「動画一覧」ボタンをクリックすると、キー項目値による絞り込みをかけた動画一覧画面へ遷移

## キー項目編集モーダル

### Purpose

キー項目の値を編集する。

### Elements

- 評価
- 日本語モードでキー項目値が「名前」の場合のみ「名前（ふりがな）」
- タグ
- 「保存」ボタン
- 「キャンセル」ボタン

### Behavior

- タグ、評価、「名前（ふりがな）」の入力

## 動画一覧画面

### Purpose

動画の一覧を表示する。

### Elements

- 画面の名称は「動画一覧」。ただし項目による絞り込み中は場合は「#{項目値}動画一覧」
- 項目による絞り込み中は場合は「絞り込み解除」ボタン
- サマリー画像
- 「タイトル」「#{キー項目名}」「カテゴリ」「名前」「公開年月日」。ただし項目による絞り込み中は場合は当該項目は非表示
- タグ、評価
- 「編集」ボタン
- 「動画詳細」ボタン

### Behavior

- タグ、評価によるフィルター
- 「タイトル」「#{キー項目名}」「カテゴリ」「名前」「公開年月日」によるソート
- サマリー画像をクリックすると、動画再生
- 「#{キー項目名}」「カテゴリ」「名前」「公開年月日」をクリックすると、それぞれの値による絞り込みを行う
- 「公開年月日」による絞り込みは「公開年」で行う
- 評価はマウスクリックにより変更できる。変更時即座に反映
- 「編集」ボタンをクリックすると、項目編集モーダルを表示
- 「動画詳細」ボタンをクリックすると、その動画の詳細画面へ遷移

## 動画詳細画面

### Purpose

動画の詳細を表示する。

### Elements

- サマリー画像
- 動画の長さ、動画サイズ、フレームレート、ファイルサイズ
- グループ化されている場合、グループ動画一覧（サマリー画像あり）
- 評価
- 各項目
- タグ
- ファイルパス
- 「編集」ボタン
- 「戻る」ボタン

### Behavior

- サマリー画像をクリックすると、動画再生
- グループ動画一覧サマリー画像をクリックすると、動画再生
- 「編集」ボタンをクリックすると、項目編集モーダルを表示

## 項目編集モーダル

### Purpose

項目の値を編集する。

### Elements

- サマリー画像
- タイトル
- 評価
- 各項目
- 日本語モードでキー項目値が「名前」の場合のみ「名前（ふりがな）」
- タグ
- 「グループ化」選択ボタン
- 「保存」ボタン
- 「キャンセル」ボタン
- 「削除」ボタン

### Behavior

- サマリー画像をクリックすると、枠内で動画を再生し、任意の時点のスクリーンショットをサマリー画像にできる
- サマリー画像設定動画は早送り、巻き戻し、ポーズ、コマ送り、スライダーによる時間移動操作が可能
- タイトル、評価、各項目、タグの入力
- 評価はマウスクリックにより変更できる。変更時即座に反映
- 「グループ化」を選択すると、同一タイトル・カテゴリ・名前・公開年月日の動画をグループ化
- 「削除」ボタンをクリックすると、表示中のデータを削除

## 設定モーダル

### Purpose

設定を編集する。

### Elements

- ユーザー定義項目（3つ）
- 項目リスト
- 言語設定
- 「保存」ボタン
- 「キャンセル」ボタン
- 「初期化」ボタン

### Behavior

- ユーザー定義項目の項目名を設定できる
- 項目リストではユーザー定義項目を含む各項目から「コメント」を除いたもの1項目をキー項目として選択できる。
- 項目リストでは「タイトル」「評価」を除いた各項目の並び替えが可能
- 項目の並び替えは動画詳細画面に反映される
- 「データ初期化」ボタンをクリックすると、設定と登録済みデータをすべて初期化
