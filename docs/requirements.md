# Requirements

## Purpose

一般向け動画管理デスクトップアプリ。
動画データを整理・評価できるようにする。

## Target Users

- 一般ユーザー

## Core Features

- 動画の登録
- 動画アイテムには以下の項目がある。
  - タイトル
  - カテゴリ
  - 名前
  - 公開年
  - 公開月日
  - 評価（5段階）
  - タグ
  - コメント
  - ユーザー定義項目（3つまで）
- 評価、タグによる絞り込み
- サマリー画像生成
- 多言語対応（当面は日本語と英語。将来的に多言語化を考慮した設計とする）

### キー項目
- コメントと評価、タグを除いた項目の1つをキー項目とし、インデックスを作成する。
- キー項目に対する評価、タグ。

## Non-goals

- アプリ内では動画再生はしない。OS標準の動画プレイヤーを起動する。
- 動画ファイルはアプリ内に持たない。ファイルへの参照パスのみ。
- 動画ファイルのメタデータの書き込みはしない。動画にひもづくデータはデータベースで保持する。
