# movieAlbum

動画を効率的に整理・閲覧するためのWindows用デスクトップアプリ。

[Github Pages](https://toruotsubo.github.io/movieAlbum/index_ja.html)

> **ステータス**: 現在のバージョンは **1.2.2** です。

---

## 📖 概要

movieAlbumは、PC内の動画ファイルを直感的なUIで分類・評価・閲覧できるデスクトップアプリです。
動画管理アプリはすでにいくつも存在しますが、動画自体にタグ付けするものがほとんどでしょう。
これでは、たとえば映画のコレクションを主演俳優別に整理したいとき、俳優の情報と映画の情報が入り混じってしまいます。
そこでMovieAlbumでは、動画一覧リストに加え、ユーザーが選択したキー項目でもリストを生成するようにしました。

- **動画データ本体は保持せず、参照パスのみを管理**します。
- OSデフォルトの動画プレイヤーと連携して再生します。
- データはJSONで管理し、動画ファイルに直接メタデータを書き込むことはありません。

## 🌟 主な機能

### 動画登録
- 初回起動時に表示される設定モーダルでキー項目指定、動画一覧画面表示選択、ユーザー定義項目（最大3つ）を設定。
  - これらの設定はいつでも変更できます。
- 設定ファイルは複数持つことができます。
- アプリウィンドウに動画ファイルをドロップすると、**動画データ編集モーダル**が自動的に開き、登録作業が始まります。

### 3つのメイン画面構成
- **キー項目一覧画面**
  - ユーザーが選択したキー項目（例：主演俳優）の一覧表示。
  - キー項目ごとのタグと評価（5段階）。
  - ドロップダウンメニュー形式のタグと評価による絞り込み。
  - キー項目によるソート。
  - 入力フォーム形式のキー項目による絞り込み。
  - 各キー項目カードに高評価動画のサムネイルを表示。
  - 各カード内のタグクリックでも絞り込みが可能。
  - 各カードの「**編集**」ボタンから**キー項目編集モーダル**を起動。
  - 各カードの「**動画一覧**」ボタンでキー項目による絞り込みをかけた動画一覧画面へ遷移。
  - テキスト表示のみの一覧も用意。項目をクリックするとキー項目による絞り込みをかけた動画一覧画面へ遷移。
- **動画一覧画面**
  - 動画の一覧表示。
  - 動画ごとのタグと評価（5段階）。
  - ドロップダウンメニュー形式のタグと評価による絞り込み。
  - タイトル、カテゴリ、キー項目、年月日によるソート。
  - 入力フォーム形式のタイトル、カテゴリ、キー項目、年による絞り込み。
  - 各動画カードにサムネイルを表示。
  - 各カード内の項目、タグクリックでも絞り込みが可能。
  - サムネイルクリックでOSデフォルトの動画プレイヤーを起動し動画再生開始。
  - 各カードの「**編集**」ボタンから**動画データ編集モーダル**を起動。
  - 各カードの「**動画詳細画面**」ボタンで詳細画面へ遷移。
  - **グループ動画スライダー**: グループ化された動画をスライダー形式で表示。
- **動画詳細画面**
  - 各動画のデータ、評価、コメント等の詳細表示。
  - サムネイルクリックでOSデフォルトの動画プレイヤーを起動し動画再生開始。
  - **動画メタデータ表示**: 再生時間、画面サイズ、フレームレート、ファイルサイズを表示。
  - **グループ動画スライダー**: グループ化された動画をスライダー形式で表示。

### 複数の設定ファイルの管理
- **ワンクリック切り替え**:
  - ヘッダー右上のドロップダウンメニューまたは設定モーダルから、複数の設定ファイルを瞬時に切り替え可能。

### その他
- **メタデータ自動解析**:
  - 動画登録時にメタデータを自動的に解析し、再生時間、画面サイズ、フレームレート、ファイルサイズを取得。
- **サムネイル画像**:
  - 動画登録時に動画再生時間の中間時点からサムネイル画像を自動生成。
  - mp4、webmなどのHTML Canvas対応動画は、動画データ編集モーダル内で動画を再生し、任意の時点の画像をサムネイル画像にできる。
  - wmvなどのHTML Canvas非対応動画は、動画データ編集モーダル内で動画をボタンにより操作し、任意の時点の画像をサムネイル画像にできる。
- **名前のふりがな**:
  - 日本語モード時は「名前」に「ふりがな」をつけ、ソートと絞り込みに利用できる。
- **グループ化**:
  - 動画データ編集モーダルで「グループ化」をONにすると、同一タイトル・カテゴリ・名前・年月日の動画をファイル名順にグループ化。
  - グループ化した動画は動画一覧画面および動画詳細画面でスライダーにまとめられる。

## 🛠 技術スタック

- **デスクトップフレームワーク**: [Electron](https://www.electronjs.org/) (v33+)
- **フロントエンドフレームワーク**: [Next.js](https://nextjs.org/) (v14 / App Router)
- **言語**: [TypeScript](https://www.typescriptlang.org/)
- **スタイリング**: [Tailwind CSS](https://tailwindcss.com/)
- **アイコングラフィック**: [Lucide React](https://lucide.dev/)
- **ビルド・パッケージング**: [tsup](https://tsup.app/), [electron-builder](https://www.electron.build/)

## 🚀 開発環境のセットアップと起動方法

### 前提条件
- **Node.js**: v18 以降推奨
- **npm** (または yarn / pnpm)

### インストール
```bash
npm install
```

### 開発モードで起動
Next.js 開発サーバーと Electron メインプロセスを並行して起動します。

```bash
npm run dev
```

### アプリのビルド & パッケージング
プロダクション用ビルドを行い、インストーラー/実行ファイルを作成します。

```bash
npm run build
```

## 📁 ディレクトリ構造

```text
movieManager/
├── electron/          # Electron メインプロセス & プリロードスクリプト & DB処理
│   ├── db/            # データベース処理 (JSONファイル保存・複数DB管理)
│   ├── main.ts
│   ├── metadataParser.ts # 動画メタデータ・フレームレート解析モジュール (Pure Node.js)
│   └── preload.ts
├── src/               # Next.js (フロントエンド) ソースコード
│   ├── app/           # App Router ページ構成
│   │   ├── movies/    # 動画一覧・動画詳細画面
│   │   └── page.tsx   # キー項目一覧画面
│   ├── components/    # UI コンポーネント (KeyItemFormModal, MovieFormModal等)
│   │   └── movie-form/# 分割フォームコンポーネント (VideoThumbnailPlayer等)
│   └── lib/           # 型定義 / 共通ユーティリティ (metadataExtractor, legacyMetadataFetcher等)
├── public/            # 静的アセット
├── docs/              # ドキュメント & 配布用ランディングページ (index.html, index_ja.html)
├── package.json
└── tsconfig.json
```
