# movieAlbum

Electron と Next.js (App Router) を活用した、ローカル動画ファイルの管理用デスクトップアプリケーションです。

> **ステータス**: 現在のバージョンは **1.0.1** です。

---

## 📖 概要

movieAlbum は、PC 内の動画ファイルをデータベース（ローカルJSONストレージ）上でメタデータ管理し、直感的な UI で閲覧・評価・整理ができるデスクトップアプリです。

- **動画データ本体は保持せず、参照パスのみを管理**します。
- 動画ファイルに直接メタデータを書き込むことはありません。
- 初回起動時やドロップ時に自動でスクショサマリー画像（720px × 405px）を作成します。
- OS デフォルトの動画プレイヤーと連携して再生します。

## 🌟 主な機能

### 1. 3つのメイン画面構成
- **キー項目一覧画面 (`#{キー項目名}一覧`)**
  - ユーザー定義キー項目ごとにグループ化された一覧表示。
  - 各キー項目ごとの評価変更・即時反映およびソート機能。
  - 評価絞り込み機能（「★4以上」「★3以上」「★5〜★1指定」）。
  - 高評価動画の自動サマリー画像サムネイル表示。
  - キー項目専用「タグ」による絞り込み機能（タグドロップダウン & タグチップ連携）。
  - 各キー項目カードの「編集」ボタンからキー項目フォームモーダルを呼び出し。
- **動画一覧画面**
  - キー項目一覧画面からの遷移時、選択されたキー項目による自動絞り込み。
  - クリックで絞り込み可能な項目（カテゴリ、名前、公開年月日、キー項目等）を分かりやすい水色で統一表示。
  - 絞り込み実行時、**実際に絞り込みに用いた項目**を動画アイテムカード内から自動的に非表示化。
  - 公開年で絞り込んだ場合のタイトル表示対応（「`#{公開年}年動画一覧`」）。
  - 動画詳細画面への遷移・復帰後もキー項目絞り込み状態を完全保持。
  - 評価絞り込み機能（「★4以上」「★3以上」「★5〜★1指定」）。
  - タイトル、カテゴリ、名前（ふりがな考慮）、公開年月日、評価によるソート機能。
  - **大量動画の高速表示**: 無限スクロールおよびサムネイル画像の遅延読み込み、グループ集計処理の最適化により、大量の動画を登録しても快適にブラウジング可能。
  - サムネイルクリックで OS デフォルトの動画プレイヤー起動。
  - 各カードの専用「**動画詳細画面**」ボタンで詳細画面へ遷移。
  - 各カードの専用「**編集**」ボタンから項目入力フォームモーダルを直接起動。
  - グループ化された親動画のサマリー画像右上に「n本のグループ」バッジを表示（兄弟動画は自動的に一覧から非表示化）。
- **動画詳細画面**
  - 各動画のデータ、評価、コメント等の詳細表示。
  - 評価の即時変更（星5段階評価）。
  - **動画技術メタデータ表示**: 再生時間、画面サイズ、フレームレート (fps)、ファイルサイズをすっきりとしたシンプルなグレーアイコンで表示。
  - **グループ動画ギャラリー機能**: グループ化された親・兄弟動画のサマリー画像を一覧表示。ファイル名順に左側から昇順で整列され、画像クリックで直接動画再生可能。

### 2. 複数データベース（設定ファイル）の管理
- **ワンクリック切り替え**:
  - ヘッダー右上のドロップダウンメニューまたは設定モーダルから、複数の独立したデータベース（設定・動画リスト）を瞬時に切り替え可能。
- **柔軟な管理機能**:
  - データベースの新規追加、削除、アクティブDBの変更に対応。
- **状態の安全なリセット**:
  - データベース切り替え時、キー項目一覧画面や動画一覧画面の絞り込みフィルターやキャッシュを自動リセットし、異なるDBデータとの混在を防止。

### 3. メタデータ自動解析 & 自動補正機能
- **高精度ネイティブバイナリ解析**:
  - MP4 / MOV（faststart未処理で `moov` アトムがファイル末尾にある動画を含む）、WebM / MKV (Matroska)、AVI 動画ファイルのメタデータ（再生時間・解像度・フレームレート fps・ファイルサイズ）を Pure Node.js で高速かつ正確に抽出。
  - ビデオトラック (`'vide'`) の厳密特定により、可変フレームレート (VFR) 動画でも正確な平均 FPS を算定。
- **欠損メタデータの自動補正 (バックフィル)**:
  - 以前登録されたメタデータ未取得動画についても、動画詳細画面を表示した際や編集時にバックグラウンドで自動的にメタデータを再取得し、DB 保存と画面表示を同期。

### 4. モーダル機能
- **キー項目フォームモーダル**
  - 各キー項目カードの「編集」ボタンから開く専用フォーム。
  - **キー項目専用評価設定**: モーダル内からキー項目自体の星5段階評価を直接設定・変更可能。
  - 「名前（ふりがな）」およびキー項目専用「タグ」の編集。
  - 「名前（ふりがな）」変更時、そのキー項目に紐づくすべての動画データの `cast_kana` に自動で一括反映。
  - アイコンを排したシンプルで洗練された入力フォームレイアウト。
- **設定モーダル**
  - **データベース管理**: 複数データベースの切り替え、新規作成、削除。
  - ユーザー定義項目（最大3つ）の項目名設定。
  - キー項目の選択・変更。
  - データ初期化機能。
- **項目入力フォームモーダル**
  - アプリへの動画ファイルのドラッグ＆ドロップ時、または各動画カードの「編集」ボタンクリック時に起動。
  - **グループ化トグルボタン**: オンにすると同一タイトル・カテゴリ・キー項目・公開年月日の動画を検索してグループ化（兄弟動画化）。オフで解除。
  - **動画キャプチャープレイヤー**: HTTP Range 部分リクエスト対応により、大容量動画でもシークバー操作が高速かつ安定。プレビュー再生・早送り/巻き戻し・**コマ送り/コマ戻し**（1フレーム移動）・シークバーによる任意フレームのスクショ指定保存。
  - **キャプチャ位置の記憶 & 自動シーク**: キャプチャ実行時の時分秒を記録。次回キャプチャ時はその記録位置へ、未記録/初回時は**動画再生時間の50%時点（中間地点）**へ自動的にシークバーを移動。
  - 動画情報の編集、入力保護、および削除機能。

## 🚀 開発環境のセットアップと起動方法

### 前提条件
- **Node.js**: v18 以降推奨
- **npm** (または yarn / pnpm)

### インストール
```bash
npm install
```

### 開発モードで起動
Next.js 開発サーバーと Electron メインプロセスを並行して起動します。

```bash
npm run dev
```

### アプリのビルド & パッケージング
プロダクション用ビルドを行い、インストーラー/実行ファイルを作成します。

```bash
npm run build
```

## 📁 ディレクトリ構造

```text
movieManager/
├── electron/          # Electron メインプロセス & プリロードスクリプト & DB処理
│   ├── db/            # データベース処理 (JSONファイル保存・複数DB管理)

│   ├── app/           # App Router ページ構成
│   │   ├── movies/    # 動画一覧・動画詳細画面
│   │   └── page.tsx   # キー項目一覧画面
│   ├── components/    # UI コンポーネント (KeyItemFormModal, MovieFormModal等)
│   │   └── movie-form/# 分割フォームコンポーネント (VideoThumbnailPlayer等)
│   └── lib/           # 型定義 / 共通ユーティリティ (metadataExtractor, legacyMetadataFetcher等)
├── public/            # 静的アセット
├── docs/              # ドキュメント & 配布用ランディングページ (index.html, index_ja.html)
├── package.json
└── tsconfig.json
```
